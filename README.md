# AccessRequest - Система запроса доступа к информационному ресурсу

## Описание
Информационная система для управления запросами доступа к корпоративным ресурсам. Сотрудники создают запросы, указывают обоснование и отслеживают статус согласования.

## Роли
- **Пользователь** - создаёт запросы, отслеживает их статус
- **Администратор** - согласует запросы, просматривает аналитику

## Функции
- Регистрация и вход пользователей
- Создание запросов доступа
- Жизненный цикл запроса: Новый → На согласовании → Одобрен/Отклонён → Выполнен
- Комментарии к запросам
- История изменений статусов
- Фильтрация и поиск
- Административная панель с аналитикой
